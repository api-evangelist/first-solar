# First Solar

> First Solar, Inc. (NASDAQ: FSLR) is a leading American manufacturer of thin-film cadmium telluride (CdTe)
> photovoltaic solar modules and a provider of utility-scale PV energy solutions. First Solar publishes no
> public API, no OpenAPI/AsyncAPI/GraphQL contract and no developer program. Its "Developer Portal" serves
> solar project developers and EPC partners, not software developers, and sits behind a Salesforce login.
> This file is generated by API Evangelist from the catalog record and from documents probed on First Solar
> hosts on 2026-09-10; it is not published by First Solar.

## About

- [First Solar](https://www.firstsolar.com): Corporate site — technology, products, projects and sustainability.
- [Technology](https://www.firstsolar.com/Technology): CdTe thin-film module technology.
- [Products](https://www.firstsolar.com/Products): Series 6 and Series 7 module families.
- [Contact](https://www.firstsolar.com/About-Us/Contact): Sales, media, supplier and recycling contact forms.

## API surface

- No public API. No OpenAPI, Swagger, AsyncAPI, GraphQL SDL, Protobuf or WSDL contract is published on any
  First Solar host. Hosts named in Certificate Transparency that look like API surfaces —
  api.firstsolar.com, ecatproapi.firstsolar.com, pmmapi.firstsolar.com, geo.firstsolar.com,
  capacity.firstsolar.com — do not resolve on public DNS and are internal only.
- No hosted MCP server, no A2A agent card, no webhook or event catalog, no SDK on any public package registry.
- [Developer Portal (login)](https://portal.firstsolar.com/developer/PortalCustomLogin): Salesforce Experience
  Cloud portal for solar project developers. Support contact EnergyCapacitySupport@firstsolar.com.

## Machine-readable documents actually served

- [OpenID Connect discovery](https://portal.firstsolar.com/.well-known/openid-configuration): The Developer
  Portal's OIDC issuer metadata — issuer https://portal.firstsolar.com/developer, 36 scopes, PKCE S256, DPoP.
- [JWKS](https://portal.firstsolar.com/developer/id/keys): RSA signing keys for the portal issuer.
- [Salesforce REST version catalog](https://portal.firstsolar.com/services/data/): 37 platform API versions,
  v31.0 through v67.0. This is Salesforce platform surface running on First Solar's tenant, credential-gated,
  not a First Solar API product.

## Provenance note

- PlantPredict, the utility-scale energy-modelling API and Python SDK First Solar built, was acquired by
  Terabase Energy in October 2021. plantpredict.com, docs.plantpredict.com, api.plantpredict.com and the
  PyPI package `plantpredict` belong to Terabase Energy and must not be attributed to First Solar.
